# 용어집

| 용어 | 간단한 설명 |
|---|---|
| Biological replicate | 같은 조건에서 독립적으로 얻은 생물학적 표본 |
| Technical replicate | 동일한 표본을 반복 측정한 것 |
| Count matrix | Gene별 count를 sample별 열로 정리한 행렬 |
| Metadata | Sample의 조건과 실험 정보를 담은 표 |
| Normalization | 관심 밖의 기술적 차이를 조정하는 과정 |
| Size factor | DESeq2가 sample별 규모 차이를 조정할 때 사용하는 값 |
| Dispersion | 평균만으로 설명되지 않는 조건 내부 변이를 나타내는 모수 |
| VST | 분산 안정화 변환(variance stabilizing transformation) |
| PCA | 다차원 데이터의 주요 변이 축을 찾는 방법 |
| Design formula | 통계 모형에 포함할 변수를 지정하는 R formula |
| Contrast | 모형에서 실제로 비교할 조건 또는 계수를 지정한 것 |
| DEG | 조건 사이에 통계적으로 유의한 발현 차이를 보이는 gene |
| FDR | 다중검정 상황에서 거짓 발견을 관리하기 위한 기준 |
| ORA | 선택한 gene 목록에서 기능 범주의 과대표현을 검정하는 방법 |
| GSEA | 순위화된 전체 gene 목록에서 gene set의 치우침을 평가하는 방법 |
