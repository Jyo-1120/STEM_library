# MOV10 예제 실습

HBC Intro-to-DGE 과정의 MOV10 예제를 재현하는 공간입니다.

## 목표

- Salmon 결과를 `tximport`로 가져온다.
- Metadata와 count matrix의 대응 관계를 확인한다.
- DESeq2 객체를 생성한다.
- Normalization과 sample-level QC를 수행한다.
- 조건별 contrast를 설정하고 결과를 해석한다.

## 데이터

대용량 실습 데이터는 저장소에 직접 포함하지 않습니다. 데이터 위치와 다운로드 방법은 HBC의 [분석 준비 단원](https://hbctraining.github.io/Intro-to-DGE/lessons/01b_DGE_setup_and_overview.html)을 참고합니다.
